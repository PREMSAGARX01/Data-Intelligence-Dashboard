📊 Data Intelligence Dashboard

An interactive Excel-based business intelligence project that transforms 250 transaction records into insights about revenue, sales trends, product performance, and customer value.

---

📌 Overview

The goal of this project is to analyze transaction data and present business performance through an interactive dashboard, PivotTables, visualizations, and analytical formulas.

It helps users explore sales performance across regions, product categories, time periods, and customers.

✨ Features

<details>
<summary><strong>📈 Interactive Dashboard</strong></summary>- KPI cards for revenue, transaction count, average order value, and quantity.
- Region and category filters.
- Start-date and end-date filters.
- Charts that respond to dashboard selections.
- Conditional formatting to highlight important values.

</details><details>
<summary><strong>🌍 Regional and Category Analysis</strong></summary>- Compare revenue across regions.
- Analyze category-level performance.
- Explore results using PivotTables, charts, and slicers.

</details><details>
<summary><strong>📅 Monthly Sales Trends</strong></summary>- Examine revenue over time.
- Use a date timeline to filter the analysis.
- Explore results with Region and Category slicers.

</details><details>
<summary><strong>📦 Product Performance</strong></summary>- Compare products by quantity sold and revenue.
- Identify high-performing products.
- Filter product analysis by region and category.

</details><details>
<summary><strong>👥 Customer Analysis</strong></summary>- Analyze customer spending.
- Rank high-value customers.
- Use formulas to support customer-level insights.

</details><details>
<summary><strong>🧮 What-If and Regression Analysis</strong></summary>- Compare Worst, Base, and Best revenue scenarios.
- Calculate the sales growth required to reach a revenue target.
- Apply "LINEST" formulas for linear regression.

Note: Goal Seek and regression are implemented using spreadsheet formulas; the built-in Excel Goal Seek tool and Data Analysis ToolPak were not confirmed.

</details>🗂️ Workbook Structure

🛠️ Tools and Technologies

- Microsoft Excel for the web
- Spreadsheet formulas and functions
- PivotTables and charts
- Slicers and date timeline
- Conditional formatting
- What-If analysis
- Linear regression with "LINEST"

🚀 How to Use

1. Download the ".xlsx" workbook from this repository.
2. Open it in Microsoft Excel or a compatible spreadsheet application.
3. Go to Dashboard to explore KPIs and filters.
4. Use the slicers and date timeline to explore different segments.
5. Review Analysis for calculations and Final Report for findings.
